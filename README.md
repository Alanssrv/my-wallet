# MyWallet

This project was developed as a personal finance management application, allowing users to track their income, expenses, and overall financial health. It provides features such as budget tracking, expense categorization, and financial reporting (in development).

I was tired of using spreadsheets to manage my finances, so I decided to create a simple and user-friendly application with features that I personally needed.

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 19.1.0.

## Upcoming features
- Connect with a service to manage data, now it's using local storage, service in development with .NET and MongoDB
- Responsive design for mobile and tablet devices
- Enhance financial reporting with visual charts
- Add authentication and user management

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
